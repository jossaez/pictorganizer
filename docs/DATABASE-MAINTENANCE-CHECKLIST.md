# Checklist manual — Mantenimiento de datos

## Resumen y salud

- [ ] 1. Crear perfil y rutinas con actividades.
- [ ] 2. Ir a Ajustes → Datos y almacenamiento.
- [ ] 3. Verificar contadores (perfiles, rutinas, actividades futuras/históricas).
- [ ] 4. Pulsar «Validar integridad» con datos correctos → mensaje positivo.

## Integridad y limpieza

- [ ] 5. Eliminar un perfil (soft-delete).
- [ ] 6. Validar integridad si quedan referencias rotas (opcional).
- [ ] 7. Confirmar limpieza de registros antiguos (solo tras 30 días o datos de prueba antiguos).

## Restablecer app

- [ ] 8. Pulsar «Restablecer PICTORGANIZER».
- [ ] 9. Confirmar en dos pasos.
- [ ] 10. Verificar redirección a onboarding.
- [ ] 11. Confirmar que el catálogo (pictogramas, rutinas plantilla) se recrea.

## Arranque y ventana rolling

- [ ] 12. Recargar la app con actividad recurrente activa.
- [ ] 13. Confirmar que se generan instancias futuras sin duplicar.
- [ ] 14. Cambiar de perfil activo sin errores.
