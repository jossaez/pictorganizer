# Checklist manual — Responsive móvil / tablet

## Móvil vertical (390px, 430px)

- [ ] Onboarding legible y usable
- [ ] Perfiles en una columna
- [ ] Agenda: anticipación, progreso y timeline apilados
- [ ] Modo niño: tarjeta “Ahora” grande, botones accesibles
- [ ] Crear actividad sin scroll horizontal
- [ ] Progreso en una columna
- [ ] Settings con BottomNav visible y sin solapamiento
- [ ] Safe area inferior respetada

## Tablet (768px, 1024px)

- [ ] Agenda adulto: columna izquierda (anticipación + progreso) y timeline a la derecha
- [ ] Modo niño: “Ahora” grande con “Después” / “Más tarde” visibles
- [ ] Modo adulto: sidebar lateral y sin BottomNav
- [ ] Rutinas en grid de 2 columnas
- [ ] Perfiles en grid de tarjetas
- [ ] Progreso: diario y semanal lado a lado
- [ ] Panel adulto con grid de tarjetas

## Forzar layout (Ajustes → Dispositivo)

- [ ] Automático: cambia al redimensionar ventana
- [ ] Teléfono: layout móvil aunque la pantalla sea ancha
- [ ] Tablet: layout tablet aunque la pantana sea estrecha

## Desktop ancho (1366px)

- [ ] Usa layout tablet (sin desktop avanzado)
- [ ] Contenido no saturado ni demasiado ancho
